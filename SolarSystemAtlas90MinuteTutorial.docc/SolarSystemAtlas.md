## Overview

이 워크숍은 제공된 `SolarSystemAtlas.xcodeproj`와 `RealityKitContent`의 태양·행성 에셋에서 시작합니다. Swift 코드는 학습자가 직접 작성하며 각 세션 끝에 실행 가능한 체크포인트와 비교합니다.

- **세션 1**에서는 볼륨 윈도우, 행성 데이터, 모델 정규화, 정적인 태양계를 만듭니다.
- **세션 2**에서는 궤도선, 공전과 자전, 행성 이름 레이블을 추가합니다.
- **세션 3**에서는 공간 탭, 선택 강조, 정보 카드, 접근성을 연결합니다.

전체 예상 시간은 90분입니다. 각 세션은 앞 세션의 체크포인트에서 이어집니다.
