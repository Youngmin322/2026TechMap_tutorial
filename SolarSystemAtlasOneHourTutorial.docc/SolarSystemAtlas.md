# SolarSystemAtlas 1시간 실습

세 개의 짧은 세션으로 나누어 RealityKit 기반 visionOS 태양계 도감의 핵심 흐름을 직접 구현합니다.

## Overview

이 실습은 준비된 `RealityKitContent` 행성 에셋을 사용해 다음 사용자 경험을 완성합니다.

- 태양과 여덟 행성을 볼륨 윈도우에 표시합니다.
- `TimelineView`의 시간으로 행성을 공전시킵니다.
- 공간 탭으로 행성을 선택하고 설명 카드를 표시합니다.

전체 예상 시간은 **55분**입니다. 세션 1은 프로젝트와 정적 장면, 세션 2는 공전, 세션 3은 선택과 정보 카드를 다룹니다. 궤도선, 행성 이름 attachment, 별도 카드 컴포넌트 같은 확장 기능은 1시간 범위에서 제외했습니다.
